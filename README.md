# Empregabilidade

Este diretório organiza duas rotinas independentes de análise das features de empregabilidade.

- [Análise dos resultados dos alunos](analise-resultados/README.md): consultas que recuperam avaliações e relatórios, extrações diárias e análises desses resultados.
- [Análise de uso das features](analise-uso/README.md): espaço para futuras consultas e análises sobre quantas pessoas utilizam cada feature.

Cada rotina possui suas próprias pastas de consultas, resultados e relatórios. Os arquivos extraídos de produção e os relatórios derivados são ignorados pelo Git, pois podem conter dados de pessoas usuárias. O `.gitignore` não controla o acesso local aos arquivos.
