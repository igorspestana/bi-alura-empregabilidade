# Análise de uso das features

Esta rotina está reservada para consultas e análises sobre quantas pessoas utilizam as features de empregabilidade. As consultas e suas definições de contagem serão criadas posteriormente.

- `consultas/`: futuras consultas SQL.
- `resultados/`: extrações obtidas ao executar as consultas.
- `relatorios/`: análises geradas a partir das extrações.

As pastas de resultados e relatórios são ignoradas pelo Git. Registre a data e, quando aplicável, o tenant ao salvar uma extração, preservando os arquivos anteriores para comparação.
